      Create the token (one time)
      
      
        
        
      1. Open github.com → your photo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
        2. 
        
      2. Name: aicon-admin. Expiration: 90 days.
        3. 
        
      3. Repository access: Only select repositories → pick aicon-hub.github.io.
        4. 
        
      4. Permissions → Repository permissions: set Contents: Read and write. Also set Actions: Read and write if you want the one-tap Telegram publish button.
        5. 
        
      5. Generate, copy the token, paste it above and tap Save.
        6. 
      
      
      
      The token is stored only in this browser's local storage. It is never sent anywhere except api.github.com, and it is never committed to any repo.
      
    
      
    
      
      
      About
      
      
      AiCoN Admin publishes guides to aicon-hub.github.io through the GitHub API. Each publish is one commit: the article, its card on the posts page, and any icon you attached. The site's build then refreshes search, the home page and the sitemap.
